## How to Contribute

We welcome contributions! Here's how you can help:

1. **Report Bugs**: Open an issue on [GitHub](https://github.com/piyushkumar-prog/geocluster/issues)
2. **Suggest Features**: Share your ideas through issues
3. **Submit Pull Requests**: Fork, create a branch, and submit a PR
4. **Improve Documentation**: Fix typos, add examples, clarify usage
5. **Share**: Star the repo and share with others

## Contribution Guidelines

- Write tests for new features
- Follow existing code style
- Update documentation as needed
- Keep commits focused and descriptive
- Be respectful and collaborative
